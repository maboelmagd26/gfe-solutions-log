# Quiz Questions

Questions I've encountered (interviews, GreatFrontEnd quizzes, courses) with my answers.

## One file per topic

- [javascript.md](javascript.md)
- [react.md](react.md)
- [frontend.md](frontend.md) — HTML, CSS, browser, web platform
- [general.md](general.md) — general software engineering

New topic (e.g. TypeScript, networking) → new file here, added to this list.

## Format

Append to the matching file:

```markdown
## What does `Array.prototype.flat` do by default?

Flattens one level deep. Pass a depth (or `Infinity`) to go deeper.

⭐ review
```

- Question = `##` heading, answer underneath. That's it.
- Got it wrong, or shaky on it? Add the `⭐ review` line. Delete the line once it sticks.
- Find everything to review: search the repo for `⭐ review`.

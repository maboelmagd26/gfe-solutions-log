# System Design

System design concepts, notes, and exercises (frontend system design included).

## How to use this section

- **Learned a concept** → create `notes/<topic>.md` (kebab-case — the name doubles
  as a future URL slug). Copy [`TEMPLATE.md`](TEMPLATE.md) if a structure helps,
  or just write plain Markdown with a `# Title`.
- **Did a design exercise** (e.g. "design a news feed") → same thing: one file in
  `notes/`, using the template's exercise sections.
- Add a row to [`PROGRESS.md`](PROGRESS.md).
